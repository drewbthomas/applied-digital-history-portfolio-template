# Working Materials

Store cleaned, normalized, selected, annotated, or otherwise transformed versions of the project material here.

Use filenames that identify the transformation or stage, for example:

```text
places-normalized.csv
records-with-coordinates.csv
corpus-ocr-corrected.zip
network-edges.csv
```

For every transformed file, document:

- The original file from which it was created.
- The tool or script used.
- The principal operations performed.
- Any records removed, merged, rejected, or left unmatched.
- Remaining uncertainties.
