# Validation

Use this folder to document how you evaluated the accuracy and historical meaning of your results.

Possible validation activities include:

- Checking a sample of transformed records against the original sources.
- Examining false matches, false positives, or classification errors.
- Comparing normalized values with the original values.
- Returning from a text-analysis pattern to the relevant passages.
- Reviewing uncertain geographic matches.
- Testing whether a result changes under different parameters.
- Recording missing, rejected, or unmatched cases.

Explain what you checked, how the sample was selected, what errors you found, and what remains uncertain. Validation does not require proving that a result is perfect; it makes the reliability and limits of the result inspectable.
