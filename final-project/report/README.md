# Short Report

Store the final short project report and any drafts required for feedback here.

The report should explain:

1. The historical question.
2. The source material and its provenance.
3. How the material was transformed into analyzable data.
4. Why the selected method was appropriate.
5. The principal results.
6. How the results were validated.
7. The historical interpretation.
8. Important limitations and unresolved questions.

The report should complement the poster rather than simply reproduce its text. Submit the final report in the format specified by the instructor.
