# Outputs

Store analytical results and visualizations here.

Possible contents include:

- Charts and tables.
- Maps.
- Network visualizations and exported graph files.
- Text-analysis results.
- Image-classification results.
- Summary statistics.

Use descriptive filenames and retain the editable or underlying data file when possible. An image alone may not contain enough information to explain how a result was produced.

For each principal output, record what data it represents, how it was created, and what historical claim it may support.
