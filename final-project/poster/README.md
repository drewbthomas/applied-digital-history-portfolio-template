# Poster

Store the editable and final versions of your academic poster here.

The final poster should include:

- The historical research question.
- Materials and provenance.
- Dataset scope and significant absences.
- A concise workflow or methods explanation.
- At least one principal analytical result.
- Historical interpretation.
- Validation, uncertainty, and limitations.
- A link or QR code to the project repository where appropriate.

Submit both the editable source file and the final PDF unless instructed otherwise.

Use clear version names, for example:

```text
poster-draft-01.pptx
poster-peer-review.pdf
poster-final.pptx
poster-final.pdf
```
