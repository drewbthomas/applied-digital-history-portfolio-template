# Processing

Use this folder for the files and documentation needed to explain how the original materials became analytical outputs.

Possible contents include:

- OpenRefine operation histories.
- Python scripts or completed Colab notebooks.
- LLM prompts used to generate or revise scripts.
- Tool settings and processing notes.
- Data schemas or field descriptions.
- Lists of rejected, missing, uncertain, or unmatched records.

Someone examining this folder should be able to reconstruct the major stages of your workflow and understand the decisions you made.
