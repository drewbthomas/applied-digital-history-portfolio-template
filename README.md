# Applied Digital History Student Portfolio

This repository is your working portfolio for **Applied Digital History: Methods and Projects**. You will use it to organize your weekly exercises, journal entries, and final project.

Your portfolio should make your research process inspectable. Preserve original material, document important transformations, retain unsuccessful or uncertain results when they are methodologically relevant, and explain how you evaluated your outputs.


## Weekly Workflow

For each week:

1. Open the tutorial in the central course repository.
2. Download any required starter files.
3. Complete the exercise using the specified tool.
4. Upload your materials, processing files, and outputs to the appropriate folder under `weekly-work/`.
5. Create a journal entry in `journal/` using the naming pattern `week-XX.md`.
6. Check that your files can be opened from the GitHub website.

Use two digits in weekly filenames and folder names:

```text
week-01
week-02
week-03
...
week-11
```

## Working Through the GitHub Website

No command-line Git knowledge is required for this course. You may create and upload files through the GitHub website.

### Upload a file

1. Open the folder where the file belongs.
2. Select **Add file**.
3. Select **Upload files**.
4. Drag the file into the upload area or select it from your computer.
5. Under **Commit changes**, enter a short description such as `Add Week 3 visualization`.
6. Select **Commit changes**.

### Create or edit a text file

1. Open the folder where the file belongs.
2. Select **Add file**.
3. Select **Create new file**.
4. Enter the complete filename, including `.md` for a Markdown file.
5. Write or paste the content into the editor.
6. Select **Commit changes**.
7. Enter a short description of the change.
8. Select **Commit changes** again to save it.

In GitHub, saving a change is called making a **commit**. For this course, a short description of what you added or changed is sufficient.

## Final Project

Your final project should connect a historical question to appropriate materials, processing methods, analytical outputs, and historical interpretation. The final-project folders are designed to preserve the complete workflow from the original material to the poster and report.

Read the `README.md` file in each final-project folder before adding material.
